Employee Management System

 Project Overview
 A Rest API-based Employee Management System developed using Java and Spring Boot to manage employee records.

 Features
 . Add Employee  . View All Employees  . Update Employee  . Delete Employee  . Search Employee 
 . User Login and Authentication  . Input Validation and Exception Handling

 Technologies Used
 . Java . Spring Boot . Spring Data JPA . MySQL . Spring Security . JWT Authentication . Maven . Postman . Swagger

 Database
 MySQL database: employee_db

 API Testing
 APIs tested using Postman and Swagger UI.

 How to Run 
 1. Clone the respository.
 2. Configure MySQL credentials in application.properties.
 3. Run the Spring Boot application.
 4. Test the APIs using Postman or Swagger UI.
